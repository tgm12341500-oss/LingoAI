LingoAI

Intelligent Language Detection System

A machine learning application that identifies the language of input text using TF-IDF feature extraction and LinearSVC classification, supporting 17 languages.

Python Scikit-learn TF-IDF LinearSVC CustomTkinter

Model Architecture

01 — Text Input

Receives text samples for language identification.

02 — Feature Extraction

TF-IDF character n-grams transform text into numerical features.

03 — Classification

LinearSVC predicts the most likely language.

04 — Prediction

The application displays the predicted language to the user.
